# CutClipper

**Cut vector clipping tool** — clips oversized cut/die vectors to the page or bleed boundary, then generates a bounding cut rectangle. Solves the problem of Illustrator files with cut paths extending far beyond the page.

**Live:** https://4003player.github.io/CutClipper/  
**Repo:** https://github.com/4003player/CutClipper.git  
**Stack:** Single-file `index.html` (~950 lines), no build step, GH Pages hosted.

## Architecture

- **pdf-lib** — PDF loading, manipulation, and output
- **pako** — content stream decompression

## What It Does

1. Loads a PDF with oversized cut vectors (common in wide-format vinyl window graphics)
2. Detects spot color layers used for cutting (backward-scan spot detection)
3. Clips all cut paths (lines and cubic Béziers) to the page/bleed rectangle
4. Generates a bounding box cut around the clipped result
5. Outputs a clean PDF that Caldera's plotter won't reject

## Key Functions

- `detectSpotColors()` — backward-scan spot color detection from page resources
- `clipBezierToRect()` / `clipLineToRect()` — geometric clipping of path segments
- `cubicRoots01()` / `evalCubic()` / `splitAt()` / `subCurve()` — Bézier math utilities
- `processContentStream()` — parses PDF content stream with CTM tracking
- `replaceContentStream()` — writes modified content back to page
- `serializeOps()` — converts parsed ops back to PDF content stream text

## Critical Rules

1. **`useObjectStreams: false`** — Caldera compatibility
2. **Spot color detection** — backward-scan approach, same as Proofmaker
3. **`numVal()` helper** — Safari compatibility
4. **`isTransparentFill()`** — detect transparent fill ops to distinguish cut vs. print
5. **CTM tracking** — `multiplyCTM()` tracks coordinate transforms through `cm` operators
